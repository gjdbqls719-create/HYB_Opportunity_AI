# HYB Engineering Handbook

Welcome to the HYB Engineering Handbook.

This handbook defines the engineering standards used throughout the HYB Opportunity AI project.

Every contributor should read this handbook before making engineering decisions.

- Shared development standards
- Reliable collaboration between human engineers and AI
