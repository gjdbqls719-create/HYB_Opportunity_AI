# 📖 문서 시스템 소개

이 문서는 HYB Opportunity AI 프로젝트의 모든 공식 문서를 관리하는 문서입니다.

프로젝트에 존재하는 모든 문서는 이 문서에 등록되어야 하며,
문서를 새로 추가하거나 삭제할 경우 반드시 이 문서를 함께 수정합니다.

---

# 📌 문서 읽는 순서

프로젝트를 처음 시작하는 경우

```
START_HERE
    ↓
DOCUMENT_INDEX
    ↓
PROJECT_STRUCTURE
    ↓
PROJECT_CONTEXT
    ↓
HYB_ENGINEERING_HANDBOOK
    ↓
SYSTEM_ARCHITECTURE
```

# 📋 문서 작성 규칙

모든 공식 문서는 다음 정보를 포함해야 합니다.

- Version
- Status
- Owner
- Category
- Priority
- Last Updated

---

# 📌 문서 관리 원칙

- 하나의 정보는 하나의 문서에서만 관리합니다.
- 문서를 삭제할 경우 Archive로 이동합니다.
- 중요한 변경 사항은 CHANGELOG에 기록합니다.
- 문서 수정 시 PROJECT_CONTEXT도 함께 확인합니다.
- 문서 추가 시 반드시 DOCUMENT_INDEX를 업데이트합니다.
