# HYB MVP Roadmap

> Version: 1.0
> Status: Active

---

# MVP Goal

HYB MVP should demonstrate that an AI can support real commerce investment decisions.

The MVP is not intended to replace human decisions.

Instead, it should provide transparent and explainable recommendations.
