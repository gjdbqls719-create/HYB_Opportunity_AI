# HYB Opportunity AI Documentation

## Purpose

HYB Opportunity AI의 공식 문서 진입점입니다.

이 문서 시스템은 프로젝트의 철학, 현재 상태, 기술 구조,
개발 과정, 운영, 품질, 사업 방향을 지속적으로 관리하기 위해 사용합니다.

## Documentation Structure

- 00_FOUNDATION: 프로젝트 철학과 핵심 원칙
- 01_CONTEXT: 현재 상태와 인계 정보
- 02_ARCHITECTURE: 시스템 설계
- 03_ENGINEERING: 개발 기준
- 04_DEVELOPMENT: 개발 기록
- 05_OPERATIONS: 운영 기준
- 06_SECURITY: 보안 기준
- 07_ROADMAP: 미래 방향
- 08_PRODUCT: 제품 정의
- 09_BUSINESS: 사업 방향
- 10_QUALITY: 품질 관리
- 11_AUDIT: 검증 기록
- 12_GOVERNANCE: 프로젝트 관리 정책

## Usage

새로운 기능, 결정, 변경 사항은 해당 영역의 문서 기준에 따라 기록합니다.
