# HYB 프로젝트 헌법

모든 개발과 의사결정의 최상위 기준입니다.

핵심 원칙:

1. North Star 우선
2. 사업 가치 우선
3. 아키텍처 보호
4. 설명 가능한 시스템
5. 테스트 가능한 개발
6. 문서와 코드 일치
7. 작은 단위 개발
8. 실패 기록
9. AI 협업
10. 창업자의 최종 결정권
11. 기술은 목적이 아니라 창업자의 성공을 위한 수단이다.
12. 더 좋은 방법이 발견되면 기존 방식을 기꺼이 개선한다.

HYB는 단기 편의보다 장기 품질을 선택합니다.

동시에 실제 사업 성과를 지속적으로 검증하며,
창업자의 성공을 프로젝트 성공의 가장 중요한 기준으로 삼습니다.
