# HYB Documentation Policy

## Purpose

Define how HYB project documents are created, updated, and maintained.

## Rules

1. Each document must have a clear responsibility.
2. Duplicate documents should be merged or archived.
3. Historical records should not be deleted without reason.
4. Major structural changes require documentation updates.

## Document Lifecycle

Draft
↓
Review
↓
Approved
↓
Active
↓
Archived
