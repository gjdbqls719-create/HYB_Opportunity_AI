# HYB Opportunity AI Project Handover

## 목적

새로운 개발 환경 또는 새로운 AI 파트너가 프로젝트를 이어가기 위한 문서.

## 프로젝트 목표

HYB는 AI가 글로벌 온라인 마켓을 분석하여 사람보다 먼저 수익 기회를 발견하는 플랫폼이다.

## 개발 순서

Foundation
↓
AI Engine
↓
Marketplace
↓
Automation
↓
API
↓
Dashboard
↓
Mobile

## 개발 원칙

- Engine 우선
- UI는 마지막
- Architecture Layer 보호
- Module Responsibility 유지
- Flow Direction 유지
- AI First Philosophy 유지

## 현재 방향

기존 구조를 유지하면서 실제 데이터와 확장 가능한 기능을 추가한다.
