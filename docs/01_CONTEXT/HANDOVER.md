# HYB Opportunity AI Environment Handover

## 새 환경 시작

1. Git Clone

2. 가상환경 생성

python -m venv .venv

3. 패키지 설치

pip install -r requirements.txt

4. 환경 변수 설정

.env 구성

5. 테스트 실행

pytest

모든 테스트 통과 후 개발 시작.
