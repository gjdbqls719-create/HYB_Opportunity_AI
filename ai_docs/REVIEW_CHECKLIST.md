# REVIEW CHECKLIST

Version 1.0

---

# 목적

PR 생성 전 AI가 반드시 확인해야 하는 체크리스트이다.

모든 항목은 YES여야 한다.

---

# 기능

□ 요구사항을 모두 만족하는가?

□ 기존 기능을 깨지 않는가?

□ 불필요한 기능이 추가되지 않았는가?

---

# Architecture

□ Layer 규칙을 지켰는가?

□ Dependency 방향을 지켰는가?

□ Domain을 오염시키지 않았는가?

---

# Code

□ Naming이 일관적인가?

□ 함수 책임이 명확한가?

□ 클래스 책임이 명확한가?

□ 중복이 없는가?

□ 불필요한 추상화가 없는가?

---

# Tests

□ 기존 테스트가 통과하는가?

□ 새 테스트가 있는가?

□ Edge Case를 고려했는가?

---

# Documentation

□ 관련 문서를 수정했는가?

□ README 수정이 필요한가?

□ Architecture 문서 영향이 있는가?

---

# Quality

□ TODO가 남아있는가?

□ Debug 코드가 제거되었는가?

□ print()가 제거되었는가?

□ 주석보다 코드가 설명적인가?

---

# Review

□ 변경 이유를 설명할 수 있는가?

□ 변경 범위가 적절한가?

□ 다른 개발자가 이해할 수 있는가?

□ 5분 안에 리뷰 가능한가?

---

# Final Check

모든 항목이 YES라면

PR 생성 가능

하나라도 NO라면

원인을 수정한 뒤 다시 검토한다.
