# CONTEXT GUIDE

Version 1.0

---

# 목적

HYB 프로젝트는 장기 프로젝트이다.

AI는 항상 필요한 Context를 먼저 확보한 뒤 작업한다.

---

# Context 종류

Quick Context

↓

빠르게 개발을 이어가기 위한 최소 정보

---

Full Context

↓

프로젝트 전체를 이해하기 위한 정보

---

# 언제 Quick Context를 사용하는가?

- 새로운 채팅 시작

- 작은 버그 수정

- 작은 PR

- 테스트 수정

- 문서 수정

---

# 언제 Full Context를 사용하는가?

- Sprint 시작

- Architecture 검토

- 큰 기능 개발

- 리팩토링

- Domain 수정

---

# Context 부족

Context가 부족하면

추측하지 않는다.

관련 문서를 더 읽는다.

# 구현 중 Context 변경

구현하면서

새로운 정보가 나오면

항상 반영한다.
